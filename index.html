About

I'm an undergraduate student (Class of 2023) in the AI Honors Program (人工智能卓越人才试点班) at the School of Computer Science, Shanghai Jiao Tong University.

My research centers on LLM Agents, with particular interest in tool use, reinforcement learning for agents, and building interpretable, human-aligned systems that bridge user intent and real-world tasks.

    IEA: Amateur-Friendly Conversational Image Editing Agent via Three Stages of Multitask Alignment

    Zichen Zhu*, Yuheng Sun*, Mingxuan Zhu, Wenjie Ma, Situo Zhang, Zhexiang Wang, Ziyue Yang, Danyang Zhang, Kunyao Lan, Zihan Zhao, Dingye Liu, Siqi Xiang, Lu Chen, Kai Yu

    CVPR 2026 Findings

    OpenReview PDF (coming soon) Code (coming soon)

    A conversational image-editing agent that learns to call 16 parameterized editing tools step by step, trained through a three-stage pipeline of SFT, GRPO with multi-objective rewards, and large-scale synthetic fine-tuning. IEA produces transparent, inspectable edit traces and outperforms tool-calling and generative baselines on both quantitative metrics and user studies.

    Keywords: LLM Agent · Reinforcement Learning · Tool Use · Image Retouch
